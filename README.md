# GDPR-Compliant-Mini-Hospital-Management-System-Implementing-the-CIA-Triad

A community hospital is transitioning from paper-based records to a digital management system. The hospital must 
ensure that personal data is processed in compliance with GDPR ensuring privacy, minimizing data exposure and 
keeping audit trails of who accesses what data and why. The Hospital administration require a privacy-centric 
dashboard that ensures: 

• Confidentiality: Patient identities and medical data are hidden or encrypted. 

• Integrity: Only authorized roles can modify or audit data; any change must be logged. 

• Availability: The system remains functional and data retrievable to authorized users.
